# Тестирование взаимодействия с Apple Watch

## Как проверить WatchConnectivity

### 1. Требования

- iPhone с iOS 14+
- Apple Watch (Series 3 или новее)
- Оба устройства должны быть:
  - Включены и разблокированы
  - Сопряжены через Bluetooth
  - Находиться рядом друг с другом

### 2. Проверка статуса в приложении

1. Откройте приложение на iPhone
2. Перейдите на вкладку "Главная"
3. Найдите карточку "Apple Watch"
4. Проверьте статусы:
   - **Сопряжено** - должны быть сопряжены через настройки
   - **Доступно** - Watch должен быть разблокирован и рядом
   - **Установлено** - приложение должно быть установлено на Watch
5. Нажмите "Обновить статус" для проверки

### 3. Что должно работать

#### ✅ Базовые проверки:
- `isPaired` - показывает, сопряжены ли устройства
- `isReachable` - показывает, доступен ли Watch для связи
- `isWatchAppInstalled` - показывает, установлено ли приложение на Watch

#### ✅ Отправка данных:
- Приложение может отправлять данные тренировки на Watch
- Команды (старт/стоп тренировки) отправляются на Watch

#### ✅ Получение данных:
- Приложение получает данные с Watch (ЧСС, шаги, калории)
- Данные отображаются в реальном времени

### 4. Отладка

#### В консоли Xcode вы увидите:
```
WCSession активирован
Watch статус: paired=true, reachable=true, installed=true
```

#### Если что-то не работает:
- Проверьте, что Watch разблокирован
- Убедитесь, что устройства рядом
- Перезапустите приложение на обоих устройствах
- Проверьте настройки Bluetooth

### 5. Тестирование без реального Watch

Если у вас нет Apple Watch, вы можете:
- Использовать симулятор Watch (ограниченная функциональность)
- Тестировать только iPhone часть приложения
- WatchConnectivity будет показывать `isPaired = false`

### 6. Следующие шаги

Для полноценной работы нужен Watch App target:
1. Создайте Watch App в Xcode
2. Реализуйте UI для Watch
3. Настройте обмен данными через WatchConnectivity
