# Боксерский трекер

Приложение для отслеживания физиологических показателей боксера с интеграцией Apple Watch и HealthKit.

## Функциональность

### 3.1.1 Трекинг сердечного ритма спортсмена
- Постоянный мониторинг ЧСС через оптический датчик Apple Watch
- Мониторинг целевых зон ЧСС с уведомлениями при выходе за пределы
- Хранение данных в приложении и синхронизация с Apple Health

### 3.1.2 Расширенная физиологическая аналитика в реальном времени
- Отображение текущей ЧСС и целевой зоны для этапа тренировки
- Индикатор "Закисления" с прогнозируемым уровнем лактата
- Счетчик "Пиковых Нагрузок" (ЧСС > 95% от максимума)
- Скорость падения ЧСС во время отдыха
- Прогноз готовности к следующему раунду (Зеленый/Желтый/Красный)

### 3.1.3 Мониторинг и прогнозирование уровня лактата
- Высокоточное прогнозирование уровня лактата в реальном времени
- Расчет на основе динамики ЧСС, данных акселерометра и гироскопа
- Анализ скорости восстановления ЧСС в перерывах
- Визуальная шкала закисления от "Норма" до "Пик"
- Отображение пикового значения лактата и времени восстановления

### 3.1.5 Сон и восстановление
- Мониторинг параметров сна через HealthKit
- Анализ продолжительности, фаз сна и пульса
- Персонализированные рекомендации по улучшению качества сна
- Оптимальное время для отхода ко сну

## Технические требования

- **Язык**: Swift
- **UI Framework**: SwiftUI
- **Минимальная версия iOS**: 18.5
- **Зависимости**: 
  - HealthKit (для работы с данными здоровья)
  - CoreMotion (для датчиков движения)
  - Charts (для визуализации данных)

## Настройка проекта

### 1. Добавление разрешений HealthKit

В Xcode:
1. Откройте проект
2. Выберите target "course work"
3. Перейдите в "Signing & Capabilities"
4. Добавьте capability "HealthKit"
5. В "Info" добавьте следующие ключи:
   - `NSHealthShareUsageDescription`: "Приложению требуется доступ к данным о здоровье для отслеживания сердечного ритма, сна и тренировок."
   - `NSHealthUpdateUsageDescription`: "Приложению требуется доступ для записи данных о тренировках и сердечном ритме в HealthKit."
   - `NSMotionUsageDescription`: "Приложению требуется доступ к данным движения для анализа интенсивности тренировок и прогнозирования уровня лактата."

Или добавьте файл `Info.plist` в проект (уже создан в папке `course work/`).

### 2. Структура проекта

```
course work/
├── Models/

```

## Использование

### Запуск тренировки
1. Откройте вкладку "Тренировка"
2. Нажмите "Начать тренировку"
3. Выберите фазу тренировки (Разминка, Рабочий раунд, Спринт)
4. Во время тренировки отслеживайте:
   - Текущий ЧСС
   - Уровень закисления
   - Количество пиковых нагрузок
5. Нажмите "Отдых" для начала периода восстановления
6. Завершите тренировку кнопкой "Завершить тренировку"

### Мониторинг ЧСС
- Просмотр текущего ЧСС в реальном времени
- Настройка целевых зон ЧСС
- График ЧСС за последние 24 часа
- История измерений

### Анализ сна
- Просмотр данных о последнем сне
- Статистика за неделю
- График фаз сна
- Персонализированные рекомендации

## Особенности реализации

### Прогнозирование лактата
Алгоритм прогнозирования основан на:
- Проценте ЧСС от максимального значения
- Интенсивности движений (акселерометр и гироскоп)
- Скорости восстановления ЧСС в перерывах
- Частоте взрывных движений

### Расчет восстановления
Статус восстановления определяется на основе:
- Скорости падения ЧСС за первые 30 секунд отдыха
- Текущего уровня прогнозируемого лактата
- Комбинации этих факторов дает цветовую индикацию готовности

## Примечания

- Для работы приложения требуется Apple Watch с поддержкой измерения ЧСС
- Данные синхронизируются с Apple Health
- Все расчеты выполняются локально на устройстве
- Прогнозирование лактата является приблизительным и не заменяет медицинские измерения
